# V19 qualification

V19 is an experimental wrapper that retains a valid existing defender after
current visible need disappears, under the original target and expiry. It
preserves selected builds, nonowned moves and immediate defensive priorities.
V2 remains the default. No V19 game results or promotion are claimed here.

The [pre-policy audits](v19-audit.md) explain the selected mechanism and its
limits; the [preregistered plan](v19-plan.md) defines the full development gate.
V18's complete two-win/four-loss result remains rejected.

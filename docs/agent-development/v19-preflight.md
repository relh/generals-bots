not a strength result, deployment qualification or promotion. V2 remains the
default and the competitive objective remains unmet.

- **58 policy cases:** 57 corrected cases on the pinned game runtime plus one
  real-engine convoy/growth/home-arrival case, with the prior module AST unchanged.
  Seventeen fixtures include eleven exact disabled V18 tuples and six winning
  V10-v6 outer-tuple/actual-inner-priority witnesses.
- **Eight prescribed runtime contexts:** enabled throughput 80.8–87.7% of V18,
  all above the 50% floor. A separate actual full-call synthetic held-replacement
  context passes at 70.2%. Disabled comparisons pass throughout. First calls on
  new game-sized shapes take 12.1–13.1 seconds; official startup remains unqualified.
- **Independent public checker:** eighteen handworked tests, including deliberate
  scalar/memory corruption; fourteen compiled score grids and actual held choices
  match exactly; all nine saved full-call outputs pass. The checker verifies real
  native defense transitions, recorded-parent attribution and outer action masks.
  It does not independently infer the original parent policy or fabricate an
  archived inner-memory oracle.
- **Complete-review adapter:** all nine saved outputs pass through the retention
  review adapter. These are isolated calls with no fabricated applied action,
  opponent decision or subsequent observation.
- **Prepared runners:** both lanes retain original opponents, consumed seed 83000,
  original keys, construction, deathtouch 800 and cap 1200. A shared barrier
  requires all eighteen V10/V10-v6/V18 controls to complete, then independently
  matches public observations, native memory, telemetry, keys and joint actions
  to the completed V18-cycle records before either lane starts V19.

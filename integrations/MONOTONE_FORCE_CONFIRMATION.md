# Conditional independent confirmation

This branch prepares one frozen evaluation only. It does not modify submitted
job-wgtyc, train another policy, upload context, or submit a job.

Prerequisite: a SHA-bound independent terminal audit with schema
`generals-monotone-force-independent-terminal-audit-v1`. The helper requires
actual provider success, verified collection and qualification, positive
selection, and the original provider/result/completion hashes. It rechecks
collected file hashes and recomputes both development comparisons from arrays.
A missing or negative prerequisite creates no runnable configuration.

After qualification, use `python -m integrations.monotone_force_confirmation prepare
--audit AUDIT --audit-sha256 SHA --source-input ORIGINAL_INPUT --output CONFIG`.
The resulting configuration freezes exact final candidate/control/source bundle
bytes, samplers, native identities and original thirteen-opponent population.
Paths describe verified local evidence; any later context staging must preserve
those artifact identities and bind its final paths in a reviewed context seal.

Only then may `run --config CONFIG --output NEW_OUTPUT` evaluate4096 games per
arm with fresh seeds12002101/12002103 and bootstrap12002111. It reuses the
existing population evaluator and map-cluster comparison. Both candidate-source
and candidate-control lower95 bounds must be positive; strata with at least100
games must have delta>=−.10. Smaller strata remain reported. No additional
training, parameter selection, or sampler change is part of confirmation.

This is not hosted winning qualification. Candidate/control checkpoint pins
cannot be filled until the real development job finishes and passes.
